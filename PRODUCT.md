# Changing Tides public interpreter demo

## Platform

Web, especially phone browsers.

## Purpose

Anyone with the public link can try actual English/Spanish voice interpretation with the existing Changing Tides demonstration agent, without a work login or Tailscale. Assignment help uses the knowledge already attached to that agent. The existing group agent and local interpreter are preserved.

## Confirmed interface

Reuse the current local interpreter's bright logo-inspired beach, portrait/landscape imagery, floating CT logo, compact controls and translucent animated words. No chat box, masthead, creator credit, provider branding or recording banner. Speech and automatic language direction start on. The visitor must tap Start talking and grant microphone access. Text entry is optional. Speaking can interrupt playback without a button.

## Demo constraints

The existing demo agent has a three-minute session limit, one concurrent conversation and twenty conversations per day. Show a remaining-time status and a clear completed state with Start again, rather than leaving a dead session. Recording remains on with seven-day retention; disclose it in the settings. Use fictional examples. The public page contains a public agent ID, never an API key, account credentials or source knowledge documents.

## Visual authority

The current local web UI and supplied CT mark are the source of truth. DESIGN.md is inherited unchanged from the original interpreter project. This is an extension of that established interface, not a new visual direction. Keep one current utterance and complete, arbitrary responses. Preserve reduced motion and phone-safe controls.
